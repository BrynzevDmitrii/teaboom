# Teaboom — карточка товара

Тестовое задание: вёрстка верхней части карточки товара интернет-магазина
[Teaboom.ru](https://teaboom.ru/product/ananasovij-ulun) на примере
«Ананасового улуна». Чистые HTML/CSS/JS, без фреймворков и сборки.

## По ТЗ

- изображение товара;
- название и категория (хлебные крошки);
- выбор фасовки (100 г / 500 г / 1000 г / 5000 г);
- артикул, актуальная и старая цена (с зачёркиванием при скидке);
- кнопка «В корзину»;
- блок с коротким описанием.

## Что сверх ТЗ

- **Своя корзина на фасовку.** Кнопка «В корзину» превращается в счётчик
  (`−` / количество / `+`) прямо на месте, без скачков высоты блока. У каждой
  фасовки — своё количество: переключаешь вес, счётчик показывает то, что
  реально в него добавлено.
- **Персистентность через `localStorage`.** Количество по каждой фасовке
  сохраняется в браузере и восстанавливается после перезагрузки страницы.
- **Просмотр фото.** Клик по изображению (или значку лупы) открывает
  увеличенную версию в модальном окне — на нативном `<dialog>`, без сторонних
  библиотек: закрытие по кресту, клику на фон и `Esc` работает из коробки.
- **Заглушка при битой картинке.** Если основное фото не загрузилось,
  автоматически подставляется брендированная SVG-заглушка вместо сломанной
  иконки браузера.
- **Адаптивность** — мобильный, планшетный и десктопный брейкпоинты.

## Архитектура

### CSS (`css/`)

Стили разбиты по смысловым блокам вместо одного файла:

| Файл | Отвечает за |
| --- | --- |
| `reset.css` | точечный сброс браузерных стилей |
| `variables.css` | CSS-переменные: цвета, радиусы, transition |
| `layout.css` | базовая раскладка страницы и заголовок |
| `gallery.css` | изображение, кнопка-лупа, заглушка |
| `breadcrumbs.css` | хлебные крошки |
| `packaging.css` | пикер фасовки |
| `price.css` | артикул и блок цены |
| `cart.css` | кнопка «В корзину» и счётчик |
| `description.css` | описание товара |
| `image-dialog.css` | попап просмотра изображения |

Размеры, завязанные на типографику (шрифты, отступы, `gap`, `border-radius`),
переведены в `rem` — чтобы карточка адекватно масштабировалась при смене
пользователем базового размера шрифта в браузере. Технические пиксель-точные
величины (обводки, `outline`, тени, брейкпоинты) намеренно оставлены в `px`.

### JS (`js/`, ES-модули)

| Файл | Отвечает за |
| --- | --- |
| `main.js` | точка входа, инициализация модулей |
| `image-gallery.js` | заглушка при ошибке загрузки фото + попап-просмотр |
| `product-cart.js` | выбор фасовки, цена, логика корзины |
| `cart-storage.js` | чтение/запись корзины в `localStorage` |
| `price-format.js` | форматирование цены под `ru-RU` |
